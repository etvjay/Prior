# Product Review Skill

## Question

Does the implementation make RFT more useful as forecast evidence, or has it drifted into another trading/crypto product?

## Review

Check:

- primary user/job remains clear;
- one live trial is still the primary interaction;
- optional trading does not dominate forecast commitment;
- no feature exists only because it is technically possible;
- no generic reputation score replaces scoped evidence;
- user can understand why RFT is different from DreamDEX itself;
- product can be demoed end-to-end;
- non-goals remain excluded.

## Adversarial prompts

- Could DreamDEX already do this without RFT?
- If trading were removed, would the primitive still make sense?
- Does this feature improve the trial evidence or merely add dashboard surface?
- Are we claiming agent capability from too little data?
- Are we conflating profitable behavior with predictive skill?
