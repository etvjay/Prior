## Source policy

- Record the exact SDK/package version used by the build.
- Re-check current primary docs before changing an external integration.
- Never infer undocumented ABI tuple shapes from prose.
- When docs and live behavior differ, log a contradiction and prefer reproducible live evidence for implementation while documenting the discrepancy.
